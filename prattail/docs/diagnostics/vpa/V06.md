# V06: VPA exact-decision complexity risk

**Severity:** Warning
**Module:** M4 VPA
**Feature gate:** `vpa`

## What it detects

V06 is a preflight complexity advisory. It fires when the pipeline summary
reports both:

- more than 20 control states; and
- failure to enter the valid exact-determinization path.

The threshold is an operational warning, not a soundness cutoff. PraTTaIL never
limits VPA stack depth or returns an approximate inclusion verdict because this
warning fired.

The historical machine-readable name `weighted-vpa-inclusion-failure` is
retained for compatibility. No inclusion operation has run at this point, so
the diagnostic must not be interpreted as an inclusion counterexample.

## Example

```text
warning[V06]: exact VPA language decisions are unavailable for a
  25-state structurally invalid analysis
  = hint: resolve visible-alphabet conflicts before requesting exact decisions
```

## What to do

1. Resolve every V05 alphabet conflict.
2. Call `validate()` on a directly constructed public automaton.
3. Remove genuinely unreachable structural states with `trim()` if the
   control-state overapproximation is unnecessarily large.
4. Run the exact Boolean inclusion or equivalence operation.

Do not add a nesting-depth bound. VPA state count does not bound accepted
nesting depth, and a three-state balanced-delimiter VPA already refutes such a
policy.

## Complexity rationale

For $`n`$ source states, exact determinization can produce as many as
$`2^{n^2+n}`$ summary states. Each state stores a relation
$`S\subseteq Q\times Q`$ and a reachable set $`R\subseteq Q`$.
Only reachable summary states are materialized, so practical cost depends on
the transition structure, but the general inclusion and equivalence problems
remain exponential-time.

Exact emptiness itself uses a finite balanced-summary saturation and has no
concrete-stack cutoff. `weighted_inclusion` is exact for the registered
`VpaDecisionSemiring` domain, currently `BooleanWeight`; arbitrary
quantitative semiring inclusion is not inferred from idempotence.
