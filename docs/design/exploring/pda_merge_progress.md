### Key insight from debugging
The stack overflow is caused by TWO monolithic functions:
- `parse_Bool` (dispatch wrapper): ~10-15KB frame in debug mode
- `parse_Bool_own_impl`: ~10KB frame

Eliminating the dispatch wrapper via PDA merge saves ~10-15KB per call, which should be enough to fix the overflow. The pre-match block adds ~32-96 bytes per ambiguous token (via `Option<Cat>` from cold helper), which is negligible compared to the savings.
